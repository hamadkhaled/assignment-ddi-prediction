# Data

- `source_cv.csv` — extraction of the `5-fold CV` worksheet (Supplementary Table S1) used by the notebook and `ddi_project.py`.
- `amiajnl-2013-002512-s2.xlsx` — the original supplementary workbook from Cheng & Zhao (2014). It is **not stored in this repository** because of its size (about 15 MB).

To run `verify_source.py`, download the workbook from PMC and place it in this folder:

https://pmc.ncbi.nlm.nih.gov/articles/instance/4173180/bin/amiajnl-2013-002512-s2.xlsx

Its expected SHA-256 checksum is listed in `../SHA256SUMS.json`.
