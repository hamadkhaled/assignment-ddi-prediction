# Data

- `amiajnl-2013-002512-s2.xlsx` — the original supplementary workbook (Supplementary Table S1) from Cheng & Zhao (2014), used by `verify_source.py`. Source: https://pmc.ncbi.nlm.nih.gov/articles/instance/4173180/bin/amiajnl-2013-002512-s2.xlsx
- `source_cv.csv` — extraction of the workbook's `5-fold CV` worksheet, used by the notebook and `ddi_project.py`.

Expected SHA-256 checksums for both files are listed in `../SHA256SUMS.json`.
